# JS Builtin Methods

JavaScript provides several built-in methods to work with different data types such as strings, numbers, objects, and arrays. These methods help manipulate and manage data effectively. Here's an introduction to some of the key methods for each data type:

1. Strings [(Learn more)](./01%20String%20Methods/)
2. Numbers [(Learn more)](./02%20Number%20methods/)
3. Objects [(Learn more)](./03%20Object%20Methods/)
4. Arrays [(Learn more)](./04%20Array%20Methods/)

### Strings

- **`length`**: A property that returns the number of characters in a string.
- **`toUpperCase()` and `toLowerCase()`**: Convert a string to uppercase or lowercase.
- **`trim()`**: Removes whitespace from both ends of a string.
- **`split()`**: Splits a string into an array based on a specified separator.
- **`includes()`**: Checks if a string contains a specified substring.
- **`replace()`**: Replaces a specified substring with another substring.

### Numbers

- **`toFixed()`**: Rounds a number to a specified number of decimal places and returns it as a string.
- **`toString()`**: Converts a number to a string.
- **`parseInt()` and `parseFloat()`**: Convert a string to an integer or float, respectively.
- **`Math` object**: Provides a variety of methods such as `Math.round()`, `Math.floor()`, `Math.ceil()`, and more for rounding and performing mathematical operations.

### Objects

- **`Object.keys()`**: Returns an array of a given object's property keys.
- **`Object.values()`**: Returns an array of a given object's property values.
- **`Object.entries()`**: Returns an array of a given object's key-value pairs.
- **`Object.assign()`**: Copies properties from source objects to a target object.
- **`Object.freeze()`**: Freezes an object, making it immutable.

### Arrays

- **`length`**: A property that returns the number of elements in an array.
- **`push()`, `pop()`, `shift()`, `unshift()`**: Methods to add or remove elements from the beginning or end of an array.
- **`slice()`**: Returns a shallow copy of a portion of an array.
- **`splice()`**: Adds or removes elements from an array.
- **`map()`, `filter()`, `reduce()`**: Higher-order functions for transforming arrays.
- **`sort()`**: Sorts the elements of an array.

These are just some of the methods available in JavaScript for managing different data types. There are many more methods and functions that you can use to manipulate data and perform various operations efficiently.
